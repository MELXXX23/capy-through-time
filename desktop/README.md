# CapyTap: Market — програма для Windows

Це та сама гра з `game.html`, тільки в окремому вікні, як звичайна програма. Працює без інтернету.
З неї можна зробити **інсталятор** (`.exe`, який встановлює гру) та **портативну версію** (один `.exe`, яку можна просто скинути другу — установка не потрібна).

## Найпростіший спосіб — двічі клікнути на файл

Папка `desktop` — це звичайна папка всередині проєкту: `C:\GAMES\capy-through-time\desktop`.
Відкрий її у Провіднику (клавіші **Win + E**, потім встав цей шлях в адресний рядок угорі і натисни Enter).

1. Встанови **Node.js**: зайди на <https://nodejs.org>, натисни зелену кнопку **LTS**, запусти завантажений файл і скрізь тисни «Next» → «Install» → «Finish». Це робиться один раз у житті.
2. У папці `desktop` двічі клікни **`install.bat`**. Відкриється чорне вікно, щось завантажується кілька хвилин. Коли напише «Готово!», натисни будь-яку клавішу.
3. Двічі клікни **`start-game.bat`** — відкриється вікно з грою як окрема програма.
4. Щоб зробити `.exe` для друзів — двічі клікни **`build-exe.bat`** і зачекай. Потім сама відкриється папка `dist`, у ній:
   - `CapyTapMarket-Portable-1.0.0.exe` — **цей файл скидай друзям** (один файл, нічого не встановлюється);
   - `CapyTapMarket-Setup-1.0.0.exe` — інсталятор (встановлює гру з ярликом).

Кроки 1–2 потрібні лише один раз. Далі, коли ти змінила гру, достатньо знову клікнути `start-game.bat` або `build-exe.bat`.

Нижче те саме, але командами — це не обов'язково.

## Що в цій папці

| Що | Для чого |
|---|---|
| `main.js` | Відкриває вікно гри (1280×720, без меню, F11 — повний екран) |
| `package.json` | Налаштування програми й збирання |
| `prepare.js` | Бере свіжий `../game.html`, робить копію в `app/game.html` і підключає локальний шрифт |
| `app/` | Копія гри + шрифт `fonts/PressStart2P-Regular.ttf` (ліцензія SIL OFL) + іконка |
| `build/icon.ico`, `build/icon.png` | Піксельна мордочка Капі (її можна перемалювати: `tools/make-icon.ps1`) |
| `dist/` | Сюди з'являться готові `.exe` після збирання |

Сам `game.html` у корені проєкту цією програмою **не змінюється**.

## Що треба один раз встановити

1. **Node.js** (версія LTS): <https://nodejs.org> → велика зелена кнопка «LTS» → встановлюй, лишаючи все за замовчуванням.
2. Після встановлення **перезапусти** термінал (або весь комп'ютер, якщо команди нижче не знаходяться).

## Як запустити гру в програмі (для перевірки)

1. Відкрий папку `desktop` у Провіднику (`C:\GAMES\capy-through-time\desktop`).
2. Натисни правою кнопкою миші на порожньому місці → **«Відкрити в Терміналі»** (або в адресному рядку Провідника напиши `powershell` і натисни Enter).
3. Один раз виконай (завантажиться Electron, це ~150–250 МБ, зачекай кілька хвилин):

   ```bash
   npm install
   ```

4. Запуск гри:

   ```bash
   npm start
   ```

   Має відкритися вікно «CapyTap: Market».

Режим тестування (кнопки «+1 година часу» та «×100 монеток» у Налаштуваннях): `npm run debug`.

## Як зібрати `.exe` для друзів

У тому ж терміналі, у папці `desktop`:

```bash
npm run dist
```

Збирання триває кілька хвилин. Коли закінчиться, у папці **`desktop\dist`** з'являться:

- `CapyTapMarket-Setup-1.0.0.exe` — інсталятор (запитає, куди встановити, і зробить ярлик на робочому столі);
- `CapyTapMarket-Portable-1.0.0.exe` — **портативна версія**: один файл, запускається подвійним кліком, нічого не встановлює. Саме її зручно скидати друзям.

Можна зібрати лише щось одне:

```bash
npm run dist:installer
npm run dist:portable
```

Щоразу, коли ти змінила `game.html` у корені проєкту, просто знову запусти `npm start` або `npm run dist` — свіжа копія гри підхопиться сама.

## Як перенести прогрес із браузера в програму

1. У браузерній грі: вкладка **⚙️ Налаштування → «Показати код» → «Копіювати»**.
2. У програмі: **⚙️ Налаштування** → встав код у нижнє поле → **«Завантажити код»** → підтверди.

Так само можна переносити прогрес назад, на телефон чи інший комп'ютер.

## Корисне

- **F11** — повний екран (Esc — вихід із нього). Пікселі лишаються чіткими за будь-якого розміру вікна: гра сама добирає цілий масштаб.
- Прогрес зберігається окремо для програми (у папці `%APPDATA%\Capy Through Time`), не змішується з браузерним.
- Другий запуск програми просто повертає до вікна, що вже відкрите.

## Якщо щось пішло не так

- **`npm` не знайдено** — Node.js не встановлений або термінал треба перезапустити.
- **Помилка про `symbolic link` під час збирання** — увімкни в Windows «Режим розробника» (Параметри → Конфіденційність і безпеко → Для розробників) або запусти термінал від імені адміністратора, і повтори `npm run dist`.
- **Windows пише «Windows захистила ваш ПК» (SmartScreen)** — це бо файл без платного цифрового підпису. Натисни «Докладніше» → «Все одно виконати». Друзям скажи так само.
- **Антивірус ругається на `.exe`** — це поширена реакція на нові незнайомі програми; для власної гри це хибне спрацювання.
- **Хочеш змінити іконку** — відредагуй малюнок у `tools/make-icon.ps1`, запусти його (`powershell -ExecutionPolicy Bypass -File tools\make-icon.ps1`), потім скопіюй `build\icon.ico` до `app\icon.ico` і збери знову.
