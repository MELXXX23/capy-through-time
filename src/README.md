# Частини гри (src/)

`game.html` — це ОДИН файл, який бачать гравці, сайт і exe. Він ЗІБРАНИЙ із частин цієї папки (порядок за іменем файлу: `010_…`, `020_…`, …).
Кожна частина починається рядком-маркером `#part ім'я` (у HTML — `<!--#part …-->`, у CSS — `/*#part …*/`, у JS — `//#part …`).
Маркери лишаються в `game.html` і нічого не роблять.

Як працювати:
- Правити можна БУДЬ-ЯКУ сторону:
  - частину в `src/` → `node tools/build.js` збирає `game.html`;
  - `game.html` напряму (старі скрипти-латки) → `node tools/split.js` розкладає по частинах (скрипти `previews/*/lib.js` роблять це самі).
- `node tools/sync.js` бере ту сторону, що змінена пізніше (його викликає `tools/publish.js` і `previews/r5/release.sh`).
- Нову частину додавай новим файлом `NNN_назва.js` з маркером на першому рядку; файл має починатися з початку рядка-банера (`/* ====`).
- Порядок важливий: усі JS-частини — один спільний скрипт (одна область видимості), тож функції й константи видно скрізь, як і раніше.

Перевірка перед випуском: `bash tools/autotest.sh` (повна) або `bash tools/autotest.sh --quick`.

## Імена частин (з раунду 47)
- Велика частина розрізана на теми: `NNN_літера_тема.js` (напр. `150_a_facade_items_decor.js`). Порядок збирання — за іменем файлу, тож літери зберігають порядок.
- Карта «що де лежить»: `MAP.md` (генерується `node tools/mkmap.js`).
- Нову частину додавай з вільним номером/літерою; не змінюй порядок наявних (const/let/виконувані оператори залежать від порядку).
- Перевірка розбиття: `node tools/check_parts.js` (текст без маркерів збігається з git HEAD; кожен маркер — справжній коментар).
- `110_a_texts_uk.js` і `110_b_texts_en.js` — дві половини одного об'єкта `translations`.

## Навігація й розбиття (з раунду 52)
- Не читай частини цілком: `node tools/c.js find|fn|outline|use|lines` (див. шапку `tools/c.js`).
- Розрізати велику частину без зміни тексту: `node tools/resplit.js src/<частина>.js <N> [--at "regexp"]`, потім `node tools/build.js && node tools/check_parts.js && node tools/mkmap.js`; нові імена додай у `DESC` у `tools/mkmap.js`.
- Довідник технічних фактів: `src/ARCH.md`.
