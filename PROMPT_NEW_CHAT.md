# Майстер-промпт для нового чату (скопіюй блок цілком)

```
Прочитай CLAUDE.md і HANDOFF.md (більше нічого наперед не читай), потім працюй над задачею нижче.

РЕЖИМ ЕКОНОМІЇ (тижневий ліміт):
1. Код шукай лише через node tools/c.js (find/fn/outline/use/lines) і Grep з head_limit ≤ 30; Read — тільки шматками ≤ 150 рядків. game.html, docs/, archive/, backups/ не відкривай.
2. Спершу план у 3–6 рядках (які частини src/ і що міняєш), потім точкові правки Edit. Не переписуй файли цілком без потреби.
3. Перевіряй текстом: tools/probe.js, javascript у вбудованому браузері, логи. Скріншот — лише щоб побачити малюнок: один кадр, scale ≤ 0,5 або zoom на ділянку; кілька кадрів — одним листом.
4. Автотест (bash tools/autotest.sh --quick, ~3 хв) — один раз у кінці задачі.
5. Незалежні дії — паралельно в одному повідомленні. Вивід команд обрізай (tail/head/cut -c1-200).
6. Відповідь коротка: що зроблено + що перевірити (3–6 пунктів). Без переказу коду.
7. Одна тема — один чат. Коли тема закрита або ~30 повідомлень — онови HANDOFF.md/PROGRESS.md, локальний коміт і скажи, що пора міняти чат.

ЗАДАЧА: <що робимо зараз>
```
