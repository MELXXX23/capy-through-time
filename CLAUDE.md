# CapyTap: Market (раніше «Капі крізь час» / Capy Through Time)

## Що це за гра
Браузерна гра-клікер з піксель-артом в одному файлі `game.html`. Капібара Капі приїжджає у вигадане піксельне місто з однією монеткою і перетворює крихітну крамничку «Усе за копійку» на торговий центр. Це ОДИН магазин, який росте на очах: крамничка → магазинчик → мінімаркет → супермаркет → універмаг → торговий центр (6 рівнів). Гравець тапає по екрану, а відділи та звірятка-працівники приносять дохід автоматично. Гра ходить через 8 епох (подорож у часі = престиж), і в кожній епосі свій вигляд міста, магазину, героїв, товарів, музики й меню.

Назва — **CapyTap: Market**. Далі планується серія окремих проєктів (CapyTap: Hotel, CapyTap: Restaurant) у тому самому стилі. Стиль: теплий затишний піксель-арт (як Stardew Valley), чіткі контури, 8-бітна музика.

## Ключові рішення гри
- Жанр: клікер + idle, сюжет по главах (8 глав + історії епох), події, престиж.
- Героїня: капібара Капі (вона/він за вибором статі), шлях «з нуля до магната».
- Помічники: 13 звірят-героїв з іменами (Голка, Бодя, Зоя, Тоня, Михась, Соня, Кря, Жужа, Лео, Пао, Мурзик, Тома, Шнирь-єнот).
- Престиж: подорож у часі, кристали часу, майстерня часу. 8 епох: Відродження, Ретро, Диско, Аркади, Інтернет, Еко, Космос, Неон.
- Події: сезони (є «Авто», вибір і Хелловін відкриваються після 2-ї епохи), розпродажі, Чорна п'ятниця, єнот-злодій, протікання даху, привиди, поштова машина, щоденний «Барабан фортуни», **Цирк Фортуни** (щоігрова доба).
- Мови: українська + англійська. Пристрої: телефон і ПК однаково важливі.
- Скіни: вкладка «Скіни», ціна 50 кристалів (`SKIN_PRICE`) або виграш у цирку; скіни Капі Мел (лисеня) і Ніка (зайчик) безкоштовні; під кожен скін є репліка `skinSay_*`. Пори року — окрема вкладка (замок до 2-ї епохи), у ній і час доби. Події трохи рідші (`evMult()` = 1,4), кнопки подій у налаштуваннях немає. Червона скринька біля синьої на дорозі — газета «Пошта від розробників» (`openNews`, `NEWS_ISSUES`, `NEWS_VERSION`): при кожному великому оновленні додай НОВИЙ випуск першим у `NEWS_ISSUES` (тексти uk/en, картинки лише до сильних змін) і піднімай `NEWS_VERSION`. У газеті кнопка «Написати розробникам» (`FEEDBACK.url/email`).

## Структура файлів
- `game.html` — УСЯ гра (HTML + CSS + JS, без бібліотек і картинок). ~560 КБ.
- `docs/index.html` — копія для GitHub Pages (робиться скриптом `tools/publish.js`; шрифт локальний `docs/fonts/PressStart2P-Regular.ttf`). Сайт: https://melxxx23.github.io/capy-through-time/ (репозиторій MELXXX23/capy-through-time).
- `desktop/` — Electron-обгортка для ПК: `main.js`, `package.json`, `prepare.js` (копіює `game.html` → `desktop/app/game.html`), `serve.js` (локальний сервер для перегляду; `.claude/launch.json`, конфіг `capy`). Збірки в `desktop/dist/`.
- `backups/` — копії `game.html` перед кожною зміною (`game_before_*.html`) і `backups/exe/` (збірки). Не потрапляє в git.
- `previews/` — зразки для узгодження з користувачем (героїв, цирку, магазинів, світу) і референси `previews/refs/` (скіни Капі). Генеруються скриптами, у git не додавати.
- `tools/` — `publish.js` (готує `docs/index.html`), `shot.js` / `shot_mobile.js` (знімки екрана гри через Electron, у т.ч. емуляція телефона), `watch-pages.sh` (стежить за публікацією на GitHub Pages).
- `PROMPTS.md` — промпти етапів 1–8 + повна історія повідомлень користувача. `PROGRESS.md` — що зроблено / в процесі / баги / далі.

## Технічні правила
- Усе в одному файлі `game.html`; графіка — піксель-арт на canvas. Спрайти — масиви рядків + `PALETTE` (кожна літера = колір), малювання через `R(g, x, y, w, h, 'літера')` і `disc`; складніші речі (чібі-покупці, цирк, хмари) — canvas, що малюється кодом.
- Сцена 320×180 «ядро» + бічні розширення (`view.offX`); світ завширшки `CONFIG.WORLD_W` (1400 на ПК, 1040 на телефоні), камера гортається (`cam`, стрілки ◀ ▶, клавіші, перетягування). Масштаб у `layoutScene` майже цілий (`snapK`, інакше дробовий), сцена на весь екран, верхня панель плаває поверх неба. ПК: частка ширини під магазин росте з рівнем (34%…49%), ×0,92; меню не зменшує картинку. Телефон: `syncPanelPad` робить так, що сцена закінчується рівно над меню (будь-якої висоти), меню на всю ширину до самого низу, `skyPad` дає запас неба при відкритому меню.
- Усі тексти — у `translations` (uk/en). Дані — у конфігах на початку скрипту. Увесь стан — у `state`.
- Збереження: `localStorage`, ключ `capyThroughTime_save` (НЕ МІНЯТИ), `SAVE_MIGRATIONS`, `mergeInto` (нові поля з типовими значеннями; масиви лишають довжину нового стану; `null` приймає лише рядки, тому «порожньо» = `-1`). Нові поля, додані пізніше: `epochEarned[]`, `epochSeen`, `activeEpoch`, `circus{next,phase,spun}`, `skinsMask`.
- Епохи: `EPOCHS`, `EPOCH_SHOP` (вигляд магазину), `viewEpoch()` (епоха для показу, може відрізнятись від `state.epoch` — перегляд пройдених епох), `EPOCH_GOODS_*` (товари), `TEAM_COSTUMES` (костюми героїв), `EPOCH_ROOF_SIGN`/`ROOF_GLOW`, меню/команда кольорами через CSS `body[data-epoch]`.
- Магазин будується `buildShopCanvas(level)`: каркас рівня + `signMotif`, `roofProp`, `epochFacadeFx`, `epochFacadeDeco` під епоху (по 1–2 тематичні деталі, щоб магазин лишався чітким).
- Хелловін (сезон halloween): замість цирку прилітає єдина відьма на мітлі (state.circus.hag=1; `hagFly`, `drawWitchSprite`), потім хатка на курячих лапках (`HAG_ART`) і гра «Три казанки» (`hagGame`) у тому самому модальному вікні, що й колесо цирку. Інших відьом у небі немає. Привиди вилітають із вікон і лякають звірят (scareNear).
- Вулиця: світ 1400 пікселів на ПК (CONFIG.WORLD_W) і 1040 на телефоні (MOBILE_PAD 360); покупці з'являються поруч із видимою частиною (passEdge), а не на краю світу.
- Дві валюти: «осколки часу» (state.shards, символ SHARD_CH у текстах → піксельний фіолетовий значок; дає лише подорож, купує лише покращення Магазину часу) і «кристали» (state.crystals; бусти/цирк/золоті покупці/завдання; купують лише скіни). Подорож: мало осколків (prestigeGain) + назавжди ×2 до тапів і доходу (eraMult). Газета: NEWS_ISSUES (новий випуск — першим), кнопка «Написати розробникам» шле на FEEDBACK.url/email (порожньо = копіює текст). Скіни Капі mel/nika безкоштовні. Єдина відьма (drawWitchSprite) прилітає на Хелловін замість цирку.
- Торговий центр має 5 поверхів: угорі кінозал (екран із рухомим «кіно» `drawCinemaMovie`, напис CINEMA через `pixText`). Нижчі рівні мають сучасні деталі `modernG` (не в епосі Відродження).
- Годинникова вежа на торговому центрі (рівень 6) малюється динамічно (drawClockTower, CLOCK_H); б'є в три ночі (clockChime), тап — подорож. Червона скринька відкриває газету (openNews, сторінки npGo).
- Цирк: фази `state.circus.phase` (0 нічого, 1 знак оклику, 2.5 їде, 2.7 розкладається, 3 стоїть, 3.5 складається, 4 їде геть); раз на ігрову добу `CONFIG.DAY_SECONDS`.
- Павільйони на поверхах: `pavilionG` (біля boxG): тип за `PAV_SEQ[епоха]`, повнота за рівнем відділу (`tiers`), зачинений = жалюзі. Вивіска «CAPYTAP» малюється ОСТАННЬОЮ (`deferSign`/`pendingSign`), декор даху — на окремому шарі з вирізом навколо неї: нові прикраси даху не ставити всередину `lastRoofSign` ±5 px.
- Магазин часу (WORKSHOP): усе дорожче й слабше навмисно, «Швидкого старту» немає; SAVE_VERSION=9 (міграція 8→9 повертає осколки). Не додавати сильних множників — гра має не прискорюватись.
- Анімація подорожі: у кожної епохи своя (WARP_BY_EPOCH[toEpoch]; налаштування немає). Умови розширення: LEVELS (25/15 … 37/27 штук) + HIRE_BY_STAGE (звірята до 2 або 3 рівня); відділів 10 (ТЦ без нових); осколки: shardBase/shardThreshold/prestigeGain, SAVE_VERSION=13 (міграція 12→13 обмежує монети під рівень; 10→11 відкочує гравців із 3+ епох у 2-гу, 11→12 дає +1 осколок за подорож); поріг подорожі ×4, дохід за подорож ×1,8. ПК: kSkyPC у layoutScene тримає ≥30% неба над будинками. Звірята ACTOR_K=1.15, Капі CAPY_K=1.3, будинки різних кольорів (houseColors).
- Відгуки: `FEEDBACK.form` (Google Форма) + `FEEDBACK.entries` (номери полів entry.…).
- Підводні камені розкладки: дорога з поштою малюється лише при `view.extraB >= 30`; на телефоні нічого не має виходити за рамки (є автоаудит `previews/r5/audit.js` для 360/390/430 px); при будь-якій зміні розкладки перевіряй ПК 1920×1080 з відкритим меню і телефон 390×844 із закритим/відкритим меню.
- Репліки (`showBubble`) не показуються поза кадром і не виходять за межі видимої сцени.
- Звук: Web Audio, `SFX`, музика по епохах і 3 стилі.

## Як працювати зі мною (користувачем)
- Спілкуйся українською, простими словами, без жаргону. Говори про себе в чоловічому роді («зробив», «додав»).
- Після завершеної задачі напиши: що зроблено і що мені перевірити (3–6 коротких пунктів). **Після КОЖНОЇ завершеної задачі оновлюй `PROGRESS.md`.**
- ПЕРЕД змінами — копія `game.html` у `backups/`. Прогрес гравців не ламати.
- Для великих візуальних змін спочатку роби зразок/перегляд («на окей»), найкраще справжніми знімками гри (`tools/shot*.js`), і чекай схвалення.
- «Збережи» = просто запам'ятай зміни (локальний коміт), БЕЗ нових exe, нових файлів і посилань. Збірку для ПК роби, лише коли прошу («зроби на пк»). Оновлюй той самий файл на столі `CapyTapMarket-Portable-NEW.exe` (якщо він запущений — буде «Device busy», тоді скажи закрити гру). У `desktop/dist` не лишай старих portable.
- На GitHub відправляй ТІЛЬКИ після мого слова «публікуй» (або «випускай»). Рецепт: `node tools/publish.js` → `node desktop/prepare.js` → коміт з трейлером `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>` → `git push` → `bash tools/watch-pages.sh 9 <слово з нового коду>`.
- РЕЖИМ БОГА: версія на ПК (exe) ЗАВЖДИ збирається з ним (desktop/prepare.js ставить DEV_OPEN_ALL=true, SKINS_FREE=true і window.__debug=true у копії desktop/app/game.html). На сайт GitHub і в телефонний сервер він не потрапляє (там у game.html обидва прапорці false; serve.js ставить CAPY_NOGOD=1). Не вмикай прапорці в самому game.html.
- Збірка exe: `cd desktop; node prepare.js; npx electron-builder --win portable --config.electronDist=node_modules/electron/dist --config.electronVersion=33.4.11`.
- Не чіпай облікові дані й паролі. Інструкція «app.setName('Capy Through Time')» у `desktop/main.js` збережена навмисно (папка збережень користувачів).

## Підводні камені
- Електрон для скриптів запускай як `env -u ELECTRON_RUN_AS_NODE desktop/node_modules/electron/dist/electron.exe ...` (інакше він працює як звичайний node). Знімки: `previews/r5/run.js` (повні), `cv.sh` (обрізка полотна), `tools/shot_mobile.js` (телефон; знімок вже обрізається до розміру екрана). Правки в game.html роби скриптами `previews/skins/patchNN.js` через інструмент Write, не через heredoc.
- У живій вкладці (порт 8080) не лишай тестових змін `state` (вони зберігаються): скидай після перевірок.
- Випуск одним скриптом: `bash previews/r5/release.sh` (publish → exe з режимом бога → копія на стіл → NOGOD prepare → коміт → push); потім `bash tools/watch-pages.sh 9 <слово>`.
- Bash на Windows ламає великі heredoc з апострофами/зворотними слешами → довгі скрипти пиши інструментом Write.
- Браузерна прев'ю-панель вузька; справжні знімки роби через `tools/shot.js` (Electron, вікно `show:true` за межами екрана; без анімації кадри не малюються).
- Сайт може оновлюватись із затримкою (GitHub Actions); телефон тримає кеш ~10 хв.
